# trans_ctrl_test1 — AK80-8透明化制御器 v1.2

Teensy 4.1 / AK80-8 KV60 / ID2 / CAN2 / 1 Mbps / MITモード用。
`control_algorithm.h`でRFOBと摩擦FFを計算し、メインスケッチの`tau_cmd`に渡します。
位置・速度・MIT Kp・MIT Kdは常に0、トルク指令周期は500 µsです。

## 操作

USBシリアル115200 bps、改行付きで入力します。`x`だけは改行なしでも直ちに処理します。

| コマンド | 動作 |
|---|---|
| `s` | SDログ作成、MITモード開始、観測器・異常ラッチを再初期化。設定ファイルの初期値を自動適用しOFFで開始 |
| `on` | フィードバックが正常な場合に制御ON |
| `off` | 制御OFF、ゼロトルク送信。観測器をリセットせず観測・記録を継続 |
| `KR 0.05` | RFOBフィードバックゲインKrを設定（ON中も変更可） |
| `KF 0.05` | 摩擦FFゲインKfを設定（ON中も変更可） |
| `STATUS` | 現在のON/OFF、Kr、Kf、運転・観測器状態、異常、指令値を表示 |
| `bias` | 制御OFFかつ静止中のドライバ推定トルクをゼロ点として取得 |
| `x` | ゼロトルク、MIT退出、ログ確定。異常ラッチは保持 |
| `d` | 停止後、最新CSVをUSB転送 |

例：`S` → `ON` → `STATUS` → `OFF`。
Kr・Kfは`control_config.h`の設定値が自動適用されるため、KR/KFコマンドの送信は不要です。
ONは設定ゲインで補償あり、OFFは補償なし（トルク指令0）です。ON/OFFでゲイン値は変わりません。
KR/KFコマンドは実行中に一時変更したい場合だけ使用します。Sで設定ファイルの値に戻ります。
コマンドの大文字・小文字は区別しません。
有限なfloatのみ受理し、NaN・Inf・範囲外表現・余分な文字列は拒否します。ゲインの上下限・平滑化はありません。
無負荷であることは操作者が確認してください。bias取得条件は速度絶対値0.05 rad/s未満で、単一の直近の有効サンプルを使用します。この条件は摩擦モデルのデッドバンドではありません。バイアスはRAM内で保持され、電源投入時は0です。

## 計算と初期化

慣性J=0.0116806、設計書の非対称Stribeck式をそのまま使用します。
速度0だけ摩擦0、平滑化や追加補償はありません。
新しい受信シーケンスごとに速度15 Hz LPFとRFOB Q=10 Hzを更新します。
両LPFは受信時刻差からalpha=1-exp(-g*dt)を計算し、受信のない間は推定値を保持します。
RFOBは `u=torque-bias-friction+J*g*velocity`, `external=J*g*velocity-x`。
初回サンプルで速度を実測値、Q状態を `J*g*velocity` で初期化し、初回推定外部トルクを0にします。
OFF中も新しいCANフィードバックにつき1回更新し、dt=0では更新しません。
ON/OFFで観測器をリセットしません。有効なフィードバックと観測器初期化が揃うまで指令は0です。
最終出力は `sat(Kr*external+Kf*friction, ±1 Nm)`、OFF時は0。
角加速度の微分、DOB、積分、ゲイン平滑化、速度超過による自動停止はありません。

## 異常処理と記録

CAN受信なし・途絶100 ms、モータエラー、送信失敗、SD書込み失敗、リング満杯で停止します。
8バイトAK80フィードバックのみ受理し、末尾のエラーコードを監視します。
CANとタイマは同じ割込み優先度で共有状態の更新を直列化します。
異常時はゼロトルクとMIT退出を試行します。通信断時の到達保証はありません。
ステータス：1=手動停止、2=CAN送信失敗、3=リング満杯、4=SD書込み失敗、
5=ログ確定失敗（表示）、6=CANタイムアウト／通信異常、7=モータエラー、8=非有限値異常。
フィードバック・観測器内部状態・ゲイン・最終指令のNaN/Infは飽和させずゼロ指令で停止し、異常を保持します。
タイムアウトや異常停止後はログ確定（SAVED表示）を待ち、明示的に `S` で再初期化してから `ON` を使用します。
`ON`だけでは復帰できません。通信停止と速度超過は独立で、速度超過停止はありません。

microSDに`TC0000.CSV`から順に保存します。Kr・Kf・ON/OFF、RFOB推定値、摩擦モデル値、摩擦FF出力、最終指令、異常コード等の21列とモデル・周期等の条件を記録します。
`D`によるUSB転送は32行ごとの受信確認付きで送信します。付属PowerShellスクリプトは全データ行と列数を検査し、一致しないファイルは完成CSVとして保存しません。
診断列にはTXキュー数、割込み間隔／直前処理時間、CAN診断スナップショット時刻・ESR1・ECR、write成功／失敗累計を含みます。CSV末尾の`#diag`には実験全体の最大値、送信失敗時スナップショット、停止理由とゼロトルク／MIT退出指令のwrite受付結果を記録します。`STATUS`でも停止後に診断セクションを表示します。
受信前のfeedback_age_usは4294967295です。CSV末尾に行数と停止理由を記録します。
ISRは2048行のRAMリングに格納するだけで、CSV整形とSD書込みはloopで行います。
SDがリング容量を超えて停滞した場合は停止します。実機で2 kHz周期とSD書込み性能を確認してください。
旧TCxxxx.BINとは別形式で、転送スクリプトもCSV用に更新しています。

## パラメータの設定場所

`control_config.h`冒頭のユーザー設定セクションに、ゲイン初期値、トルク上限、周期、Q/速度LPF、慣性、正逆転摩擦モデル、CAN、MIT範囲、タイムアウト、ログ設定を集約しています。
`INITIAL_ENABLED`・`INITIAL_K_R`・`INITIAL_K_F`は起動／S時の初期値です。
実行中の適用値は`.ino`の単一の`runtime.enabled`・`runtime.Kr`・`runtime.Kf`で保持し、STATUSとCSVは同じ値を参照します。

```powershell
.\download_trans_ctrl_test1.ps1 -Port COM5
```

ビルド例（書込みは別途実施）：

```powershell
arduino-cli compile --fqbn teensy:avr:teensy41 .\trans_ctrl_test1
```
