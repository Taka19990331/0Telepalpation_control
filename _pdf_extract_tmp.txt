Product Features
The AK series motor driver board adopts high-performance drive chips in the same class, uses
Field Oriented Control (FOC) algorithm, and is equipped with advanced self-disturbance control
technology for speed and angle control. It can be used with CubeMarsTool parameter setting
software for parameter setting and firmware upgrades. In terms of hardware, the inner loop uses
a 16-bit high-precision encoder, supporting up to 21 bits (custom firmware required), and the
CAN communication uses a safer isolated CAN interface, along with a more reliable plug, greatly
enhancing the reliability of the product's use and communication; in terms of software, the
upper computer CubeMarsTool has been fully upgraded, and there is no need to switch between
servo mode and force control mode, the control interface is more concise, and a large number of
simplifications have been made in the operation, fully improving the customer's experience.

3.1.1 Configuration
3.1.1.1 Basic Settings
The Basic Settings interface allows users to configure motor parameters and communication
parameters; The Motor Settings section supports motor parameter identification, encoder
parameter calibration, and parameter reading and writing. For specific motor calibration
operations, see section 3.2. The Application Settings section supports settings for CAN port mode,
CAN bus rate, CAN feedback rate, CAN ID, and serial port baud rate, which users can match
according to actual conditions.
The CAN port mode is divided into two types: periodic feedback and query-reply. Periodic
reporting will provide messages at regular intervals based on the CAN feedback rate; the
query-reply mode only sends back message reports when the motor receives the correct control
commands.

3.1.3 Real-time Data
This page supports viewing real-time data feedback and debugging interface, as well as plotting
graphs. The data includes:
-DQ: DQ voltage represents the motor voltage converted onto the D-axis and Q-axis, and DQ
current represents the motor current converted onto the D-axis and Q-axis.
- Current: Current in indicates the motor's input current, Current motor indicates the motor's
phase line current, and Duty cycle indicates the motor's duty ratio.
- Temperature: Temperature MOSFET indicates the temperature of the motor's MOS transistor,
and Temperature Motor indicates the motor's temperature.
- Speed: ERPM indicates the electrical rotational speed of the motor's rotor.
- Position: Position indicates the position of the motor's rotor.
- Encoder Angle: Encoder angle indicates the angle of the encoder.

4. Driver Board Communication Protocol and Description
4.1Servo Mode Control Modes and Description
There are 6 control modes in the servo mode, each corresponding to a specific ID number.
Duty Cycle Mode: A specified duty cycle voltage is given to the motor, similar to square wave
drive form;
Current Loop Mode: A specified Iq current is given to the motor, and since the motor output
torque = iq*KT, it can be used as a torque loop (KT data can be referenced on the official
website);
Current Brake Mode: A specified braking current is given to the motor to hold it in the current
position (pay attention to motor temperature when using);
Velocity Mode: A specified operating speed is given to the motor (acceleration is default to the
maximum value);
Position Mode: A specified position is given to the motor, and the motor will move to the
specified position (speed and acceleration are default to the maximum value);
Position-Velocity Loop Mode: A specified position, speed, and acceleration are given to the
motor.

1.1.1 Configuration
1.1.1.1 Basic Configuration
The Basic Settings interface allows users to configure motor parameters and communication
parameters; the Motor Settings section supports motor parameter identification, encoder
parameter calibration, and parameter reading and writing; for detailed motor calibration
procedures, refer to Section 1.2; the Application Settings section supports configuration of CAN
port mode, CAN bus rate, CAN feedback rate, CAN ID, and serial port baud rate, enabling users to
select appropriate settings based on actual operating conditions.
The CAN bus mode consists of two types: periodic feedback mode and request-response
mode. In periodic feedback mode, message packets are transmitted at regular intervals based on
the CAN feedback rate; in request-response mode, message packets are transmitted only when
the motor receives the correct control command.\n\n==== C:\0Telepalpation_control\ak-series-motor-module-v3-driver-software-user-manual-en.pdf PAGE 7 ====\nE-mail:info@cubemars.com
https://www.cubemars.com/
Motor parameter identification can be performed to verify
whether the motor is in motion via the position curve; once completed, the system will
automatically stop and update the motor parameters to the upper computer.
⚠ : The entire motor parameter identification process must be conducted under no-load
conditions; otherwise, it may result in inaccurate parameter identification or motor damage.
At the start of the identification process, a sharp, brief sound will be heard, after which the
motor will begin to rotate accompanied by increased noise.
By performing encoder parameter identification, you can verify
whether the motor is in motion via the position curve; once completed, the system will
automatically stop and update the encoder parameters to the upper computer.
⚠ : During the entire motor encoder parameter identification process, the motor must remain
in no-load condition; otherwise, inaccurate parameter identification or motor damage may
occur. The identification process will produce a relatively high-pitched noise and cause
significant motor heating; repeated consecutive executions of this process may lead to a
sudden rise in motor temperature.

2. Driver Board Communication Protocol and Description
2.1 Servo Mode Control Modes and Description
The servo mode offers six control modes, each associated with a specific ID number.
Duty cycle mode: A specified voltage is applied to the motor based on a predefined duty cycle,
similar to square-wave drive operation;
Current loop mode: Given the specified Iq current of the motor, since the motor's output torque
is given by iq × KT, this mode can be used as a torque loop (the KT value can be referenced from
the parameter range specified in the force control mode communication protocol);
Current braking mode: Set the specified braking current for the motor to lock it in place at its
current position (take note of the motor temperature during operation);
Speed mode: specifies the operating speed of the motor (with acceleration set to its maximum
value by default);
Position mode: Given a specified target position for the motor, the motor will move to that
specified position (with speed and acceleration set to their maximum default values);
Position-velocity loop mode: specifies the desired position, velocity, and acceleration of the motor.
Data definition for the servo mode drive board
Identifier: Control Mode ID + Drive ID; Frame Type: Extended Frame
Frame format: DATA; DLC: 8 bytes
The servo motor employs the CAN protocol, utilizing an extended frame format as shown below.

void comm_can_transmit_eid(uint32_t id, const uint8_t *data, uint8_t len) {
uint8_t i=0;
if (len > 8) {
len = 8;
}
CanTxMsg TxMessage;
TxMessage.StdId = 0;
TxMessage.IDE = CAN_ID_EXT;
TxMessage.ExtId = id;
TxMessage.RTR = CAN_RTR_DATA;
TxMessage.DLC = len;
for(i=0;i<len;i++)
TxMessage.Data[i]=data[i];
CAN_Transmit(CHASSIS_CAN, &TxMessage); //CAN send TxMessage data
}
void buffer_append_int32(uint8_t* buffer, int32_t number, int32_t *index) {
buffer[(*index)++] = number >> 24;
buffer[(*index)++] = number >> 16;
buffer[(*index)++] = number >> 8;
buffer[(*index)++] = number;
}
void buffer_append_int16(uint8_t* buffer, int16_t number, int16_t *index) {
buffer[(*index)++] = number >> 8;
buffer[(*index)++] = number;
}

2.2 Force Control Mode(MIT) Communication Protocol
The force control mode comprises three control modes, all of which share a single control ID; the
specific control mode is determined based on the transmitted data. For detailed operations of each
mode via the upper computer, refer to section 1.3.2.
Position loop mode: The motor operates solely based on the specified target position and the Kp
and Kd values; the motor will then rotate toward the specified position.
Speed loop mode: When only the motor operating speed and the Kd value are specified, the motor
will rotate at the specified speed;
Current loop mode: The motor operates solely based on a specified torque value, rotating to
achieve that torque.
The force control mode utilizes the CAN protocol and employs an extended frame format as shown
below.
