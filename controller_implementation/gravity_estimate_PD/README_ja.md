# gravity_estimate_PD

Teensy 4.1でAK80を2台同時にMITトルクモード制御し、開始角保持に必要なトルクをmicroSDへ記録するスケッチです。

## 制御

- Motor ID 1 / CAN1 と Motor ID 2 / CAN2 を500 µs周期（2 kHz）で制御します。
- `S`を受けた後、両モータの有効なフィードバックを待ち、それぞれの角度を保持目標として記録します。
- フィードバック角度にゼロオフセットを加えず、エンコーダ原値を目標・ログに使用します。エンコーダゼロ設定コマンドは送りません。
- 外部制御器は `tau = 0.00834 * (target_deg - angle_deg) - 0.1 * velocity_rad_s` です。指令トルクは±3 N·mで制限します。
- MITフレーム内の位置、速度、Kp、Kdは0です。移動平均、デッドバンド、RFOB、摩擦補償、チャープはありません。

## 操作と記録

USB Serialは115200 bpsです。microSDを挿入してから使用してください。

| 操作 | 動作 |
| --- | --- |
| `S` + Enter | 新しいCSVを作り、2台を有効化して初期角度を取得し、PD保持と記録を開始 |
| `X` | ゼロトルクを送り、両モータを無効化して記録を確定 |
| `STATUS` + Enter | 運転状態と保持目標・現在の指令トルクを表示 |
| `D` + Enter | 停止後に最新CSVを共通ログ転送で取得 |
| `LOG,1,FETCH,LATEST` + Enter | 共通ログ転送で最新CSVを取得 |

ログは `GPD0000.CSV` から作成します。冒頭に制御ゲイン、周期、モータ/CAN割当、MIT内部ゲイン、取得した保持目標角を記録し、データ部には時刻と各モータのフィードバック角度・速度・指令トルク・フィードバックトルクを記録します。

通信途絶、モータエラー、数値異常、送信失敗、ログリング満杯、SD書込み失敗では運転を停止し、ゼロ指令と無効化を試みます。通信異常時は停止指令の到達を保証できません。

ログ末尾の`#stop_reason`とシリアルの`SAVED,...,STATUS,...`は同じ番号です。1=手動停止、2=CAN送信失敗、3=ログリング満杯、4=SD書込み失敗、6=フィードバックタイムアウトまたは起動時応答不成立、7=モータエラー、8=数値異常です。

Arduino IDEではこのフォルダ内の `gravity_estimate_PD.ino` を開き、Teensy 4.1を選択してください。実機書込み・モータ動作・SD記録は未確認です。
