# 既存Motor1データの診断結果

## 実施内容

2026-09-16。`diagnose_identification_data.m`をMATLAB R2026aで実行し、終了コード0を確認。
元の2つの解析プログラムとCSVは変更していない。機械モデルの当てはめ・物理パラメータの推定は行っていない。
対象は前回の比較に使用したMotor1の2本であり、他モーターの検査結果ではない。

実行方法：MATLABでMATLAB_Analysisフォルダーを開き、`results = diagnose_identification_data;`。
元の`compare_identification_inputs(false)`を呼び出して同じFRFを再計算する。
FRFは元と同じFs=2000、先頭5秒相当の行を除外、detrend、4096点Hann窓、50%重複、FFT32768点。
時系列図にはCSVのTime_msを用いた。FRFの周波数軸は時刻補正していないため約1.2%の尺度誤差が残る。
結果は本フォルダーのPNG、CSV、MATに保存。execution_log.txtは実行履歴を追記するため、途中の試行も含む。

## 1. 位相ジャンプ：表示上の折り返しと確認

| データ | 入力 | 周波数区間（暫定Hz） | 元表示の差 | 連続位相の差 | 区間の最低coherence |
|---|---|---|---|---|---|
| 172605 | 合計トルク指令 | 8.4839–8.5449 | +359.966° | −0.0340° | 0.9926 |
| 170331 | チャープ | 19.5313–19.5923 | +359.946° | −0.0537° | 0.9991 |

`angle`が±180°で折り返すために生じたジャンプ。診断版は帯域内でunwrapした位相を「Phase」と表示する。
プログラム冒頭の`SHOW_WRAPPED_PHASE = false`が既定。`true`にするとWrapped phaseの診断パネルを追加する。
FRF凡例は「1: Chirp cmd only input」「2: PD + chirp cmd input」「3: Measured torque input」に統一。
各曲線の開始位相を(-360,0]の枝に置き、比較時の定数360°差も除いた。この操作は絶対位相の校正ではない。
元と表示変更後の複素位相が一致することをassertで検証した。FRFの振幅・複素数値には変更を加えていない。
この2箇所のジャンプは実験異常の証拠ではない。ただし、データ全体が正常という意味ではない。

## 2. トルク指令とフィードバックに大きな差

合計指令→トルクフィードバックのFRFを追加計算した（機械モデルのフィッティングではない）。

- 172605、1–10 Hz：振幅比0.630–0.685、中央値0.637。
- 170331、10–100 Hz：振幅比0.434–0.637。約10 Hzでは約0.63、100 Hz付近では約0.43。
- 高周波データではフィードバックが合計指令に対して遅れ、100 Hz付近で約−74°。

トルクフィードバックを入力とした位置FRFが大きくなり、位相も合計指令入力の場合と異なる理由の一つである。
時系列の拡大図でも振幅差が見える。
原因が実トルクの追従性なのか、換算係数、ドライバ内フィルタ、ログの時刻対応なのかはCSVだけでは確定できない。
この差を単に校正係数で補正したり、フィードバック値を真の軸トルクと断定したりはしない。

## 3. 時系列に見られる特徴

### 低周波側 172605

- 記録304秒、チャープは約2–302秒、振幅2 Nm。
- 角度範囲−137.6222～−42.1511°（約95.5°の全振幅）。初期位置付近を中心とするが、微小変位の実験ではない。
- 3～5秒の拡大図では、速度ゼロ付近で短い平坦部、トルクにも折れ曲がりがある。摩擦等の非線形性を疑うが原因は未確定。
- 最大の隣接角度差は0.3498°、83.027秒付近。拡大図では連続した運動中の変化であり、孤立した巨大な角度飛びには見えない。
- 合計指令とフィードバック入力の低周波coherenceは一部で0.9付近まで低下する。全帯域平均の高さだけで品質を判断しない。

### 高周波側 170331

- 記録114秒、チャープは約2–112秒、振幅5 Nm。
- 開始直後に大きな過渡応答がある。最大隣接角度差0.2842°は2.045秒付近のその過渡中にある。
- 元の解析は先頭5秒相当を除外しているため、この開始直後のピークはFRF計算には含まれない。
- 角度が後半で非常に小さくなる一方、トルク入力は続く。高周波での量子化・信号対雑音比は今後のモデル化で考慮する必要がある。

全体図は各時間ビンの最小値・最大値を結んだ包絡表示。ビン幅と信号周期の関係で局所的なくびれが見えることがある。
くびれを欠測・停止と断定せず、判定には元サンプルの拡大図と時刻差を使う。

## 4. 速度積分と角度変化の不一致

同じミリ秒時刻のサンプルを平均し、全ユニーク時刻上で速度を台形積分した。
角度変化から速度積分を引いた終端差は、172605で約2.745 rad、170331で約1.040 rad。
差は概ね時間に比例して増え、時間平均で約0.00903、0.00912 rad/sの速度偏りに相当する。
大きな角度ドリフトが実際に起きたという意味ではなく、速度ログを積分した値が位置ログと一致していないということ。
現行コードの速度量子化幅75/4095≒0.018315 rad/sの半分に近く、ゼロ付近の偏り・量子化や変換処理を調べる手掛かりになる。
取得時コードの対応やタイムスタンプ精度も未確定なので、量子化が原因とは断定しない。
今回の位置FRFは速度を直接入力にしていないため、この積分ドリフトをそのまま位相ジャンプの原因とはしない。

## 5. 記録整合性

| 項目 | 172605 | 170331 |
|---|---:|---:|
| 行数 | 601039 | 225254 |
| 時刻からの平均記録レート | 1977.105 Hz | 1975.921 Hz |
| 最大時刻差 | 1 ms | 4 ms（約70.945秒） |
| 時刻逆転 | 0 | 0 |
| NaN/Inf | 0 | 0 |
| 非ゼロエラーコード | 0 | 0 |
| 合計指令−PD−チャープの最大絶対差 | 0.00001 Nm | 0.00001 Nm |
| 合計指令の最大絶対値 | 2.16576 Nm | 5.85014 Nm |

同一ミリ秒時刻の行は多いが、約2 kHzに対して時刻分解能が1 msなので、これだけで重複記録・欠測とは言えない。
合計トルクの代数関係は全行で一致する。これはログ上の一致であり、CAN送信成功や実トルクの非飽和を証明しない。
4 msの間隔は記録の局所的不規則性を示すが、原因と失われたサンプル数は確定しない。

PDトルクを角度・速度から回帰した補助値もsummary.csvに保存した。低周波側Kp≈0.0403、Kd≈0.1986、高周波側Kp≈0.0531、Kd≈0.1973。
これは取得時のゲインを確定する値ではない。最新フィードバックと直前指令の記録ずれや非線形性が回帰値へ混入し得る。

## 判断

位相ジャンプは表示修正で解消した。次にモデル当てはめへ進む前の主な注意点は、トルク指令とフィードバックの尺度・遅れの違い、
低速時の非線形性、速度ログの小さな偏り、時刻情報とサンプリング設定の不一致である。
これらは「データが使えない」という結論ではなく、フィッティング結果を物理パラメータとして解釈する際の未解決事項である。
