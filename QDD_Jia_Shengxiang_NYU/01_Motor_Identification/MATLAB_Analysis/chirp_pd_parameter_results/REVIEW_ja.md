# Chirp only / PD+chirp: J・D比較

## 目的と条件
同じ2実験の既存FRF（individual_analysis.mat）を読み、入力定義のみを変えた比較を実行した。生CSVからのFRF再推定は今回行っていない。元FRFは各CSVの平均記録レート（1977.105 / 1975.921 Hz）で推定済み。

全6条件で P(s)=exp(-Td*s)/(J*s^2+D*s) を使用。Chirp onlyには保持PDを含めた閉ループモデルを使わず、元解析のモデル構造の問題を可視化する。したがってChirp onlyのJ・Dは物理的な慣性・粘性とは解釈しない。以前のidentify_each_experiment.mのChirp onlyはPDを含むモデルであり、そのパラメータとは直接比較しない。

低周波単独1.2–19 Hz、高周波単独12–110 Hz、結合後1.2–110 Hz。12–19 Hzで複素FRFを対数周波数上のcosine重みで結合し、ゲインや位相の人為的な整合はしない。「平滑化」は接続重みの滑らかな切替であり、帯域全体を移動平均する処理ではない。

全条件で共通の対数周波数格子を使用し、各段階では両入力のコヒーレンス>=0.9を満たす同一周波数点を使う。結合部の品質指標は両元FRFのコヒーレンスの最小値で、結合FRF自身のコヒーレンスではない。目的関数は平均{ゲイン誤差[dB]^2+0.05*円周上の位相誤差[deg]^2}、9初期値から探索。以前の個別同定と補間格子・重みが多少異なるため値は微小に変わる。PD+chirp結合後は既存merge_pd_chirp_frfの値を再現。

Chirp onlyのJはPD+chirpに対し低周波-36.49%、高周波-4.76%、結合後-20.53%。Dはそれぞれ10.79倍、6.78倍、10.62倍。

## 考察
- 入力からPDトルクを除いたまま機械モデルを当てると、保持PDの効果がJ・D・遅延の推定に入り込む。特に低周波の位相形状を再現できず、滑らかにつないでもこの問題は解消しない。
- 高周波ではChirp onlyでもFRFとモデルがよく合うが、Dの値はPD+chirpと大きく違う。見た目の一致だけでは物理パラメータの妥当性は確認できない。
- 理想的な保持PDを含むChirp→位置応答には分母の粘性項D+Kdに加えて剛性項Kpも現れる。今回のChirp onlyモデルにはそれらがない。D差をすべて実機の摩擦差と解釈してはいけない。
- PD+chirpのJは低周波と高周波で約1.5%の違い。Dは約29%（高/低-1）異なり、帯域・重みへの感度が残る。これは振幅依存性の証明ではない。
- 単独帯域と結合後では使用帯域も変わるため、その推定値差を平滑化だけの影響とは言えない。
- PD+chirpもトルク指令から位置までの等価モデルで、ドライバ特性を含みうる。独立検証・信頼区間の推定はしていない。
