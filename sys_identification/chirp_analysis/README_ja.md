# QDD チャープのオフライン同定

MATLABで `analyze_chirp.m` を実行してください。冒頭の `dataName` だけを変更できます。
拡張子は省略可能です。実験CSVと制御プログラムは変更しません。
結果は `results/<CSV名>/` に保存されます。同じデータ名で再実行すると結果を更新します。

## 入力と単位

対応形式は `CHIRPSI1_CSV_WITH_METADATA_V1`、AK80標準MIT、正常完了した対数チャープです。
未対応形式、必須メタデータ欠落、不正時刻、欠損、飽和、PD不一致は原因を表示して停止します。
古いCSVに現在のファームウェア設定を代入することはありません。
全メタデータを表示・保存し、実験条件はCSVのみから取得します。

確認した定義は `../chirp_si1.py`、`../chirp_simplified_test1/chirp_simplified_test1.ino`、
`motor_protocol.h` にあります。

- PはNm/degなので `180/pi` を掛けてNm/radへ換算。Dは既にNm/(rad/s)。
- 角度はdegree→rad。速度は元からrad/sです。
- AK80 MITの角度・速度・トルク要求値を直接使用。追加の減速比換算はしません。
  CSVとコードには独立した実トルク校正の証拠がありません。出力軸Nmという指令の解釈に
  条件付けたJ/Bであり、物理トルクの絶対値が検証されたという意味ではありません。
- 初期平均区間ではPDが無効です。その区間は図示しますが閉ループ同定には使いません。
- 加振＋PDのみの後保持区間を同定に使用します。初期角度・速度は先頭実測値に固定します。
- 記録された `chirp_Nm` が入力です。欠落時のみCSVの対数チャープ式、振幅式、
  開始インデックス・fs・ゼロ初期位相から再構成します。
- 多回転位置を無条件に`unwrap`しません。範囲外・不連続は解釈できないため停止します。

## 推定方法と限界

`J*x''+(B+Kd)*x'+Kp*x=u` のJとBのみを推定します。
実測指令時刻間をZOH（零次ホールド）とし、行列指数による厳密な状態遷移を使います。
等間隔時は同値な`filter`再帰により高速化します。不等間隔時は各実測周期で伝播します。
記録値の平滑化・間引き・加速度の数値微分・自動時間シフトは行いません。

`fminsearch`に `J=exp(z1), B=exp(z2)` を渡し、さらにB=0境界を別途探索します。
CSVの周波数帯と既知ゲインから初期値スケールを作り、12通りの開始条件を比較します。
収束した候補のうち角度の正規化MSEが最小の解を採用します。
標準MATLABのみで解析でき、追加Toolboxのライセンスを必要としません。
インストール済み製品はCommand Windowに表示します。

Fitは `100*(1-norm(x-x_model)/norm(x-mean(x)))`、RMSEはradです。
同じ実験への当てはまりであり、独立した検証データでの予測精度ではありません。
初期値ごとの結果、相対スケールでの感度条件数、Jを再最適化したBの誤差プロファイルも保存します。
B=0付近、初期値依存、平坦なプロファイルは識別性不足の兆候です。
プロファイルを統計的な信頼区間とは解釈しません。

## FRF

既知チャープ位相のsin/cosに、局所定数・線形トレンドを加えたHann重み付き回帰を行い、
出力と入力の複素係数比を求めます。周波数追従により掃引全体の単純FFT比を避けますが、
局所定常近似なので過渡応答・急速な周波数変化・低SNRの影響は残ります。
既定の窓幅は中心周波数における4周期です。回帰に正確なチャープ位相を使うため、
窓内の周波数変化率を固定上限で足切りしません。相対帯域幅は診断量として保存します。
2周期未満、または設計行列の条件が悪い点だけをFRF回帰不能とし、灰色の×で表示します。
記録端で切れる窓も、2周期以上かつ数値的に安定なら推定に残し、`windowStatus`に明示します。
この判定はFRF局所推定に限り、時間領域モデルフィッティングのデータ選別ではありません。
`usableWindow`は窓条件だけの判定で、
信号対雑音比やモデル適合を保証しません。`localRegressionR2`はCoherenceではありません。

理論FRFに加え、モデル時系列に同じ局所推定を適用した曲線を表示し、
掃引・推定器による偏りとモデル不一致を区別できるようにしています。
図の位相は連続表示用にunwrapし、CSVには主値とunwrap値を保存します。
位相誤差は複素比の主値で比較します。
Figure 2はゲイン・位相・Coherenceの3段構成です。Coherence欄は縦軸0～1と0.9基準線を示し、
推定値がない場合は理由を明示します。今回のCSVは1回の非定常な対数掃引で、同じ周波数を
独立に繰り返したデータがありません。Welch法は分割数、窓長、重なり、平均数を選べますが、
この掃引では各時間区間が異なる瞬時周波数を含みます。したがって、それらは同一周波数の
独立平均とは解釈できず、恣意的な分割条件によるCoherence曲線や0.9未満の帯域を出しません。
今回のCoherence値は欠測（NaN）です。Coherence<0.9の領域も判定不能で、0とは扱いません。
低Coherenceだったと結論付けることもできません。SNR不足・非線形性・非定常性は一般的な候補ですが、
この記録では原因をCoherenceで切り分けられません。ゲイン・位相の差と時間領域の適合度は別途評価し、
Coherenceが低い周波数を理由にモデルフィッティングから除外しません。
低周波・端点で窓条件を満たせない場合、その帯域のゲイン・共振は確認不能と明記します。

実測フィードバックは同じ行の指令送信より前のスナップショットです。
記録されたfeedback_ageから時間ずれを診断しますが、通信・ドライバ内部の総遅延は推定しません。
連続時間PDモデルと実機のサンプル保持PDの差も特に高周波に残り得ます。
摩擦、コギング、バックラッシュ、指令量子化、トルク校正、ドライバ応答などはモデルに追加しません。

## 出力

- `analysis.mat`：条件、前処理データ、J/B、予測、残差、診断、FRF、Coherence可用性を含む`r`構造体
- `parameters.csv`、`csv_conditions.csv`、`multistart.csv`、`B_profile.csv`、`frf.csv`
- `report.txt`：パラメータ・適合度・周波数比較・解釈上の制約
- Figure 1～5のPNGと編集可能なFIG

`test_qdd_chirp_analysis`はControl System Toolboxの`lsim`を独立した合成データ生成器として
使い、J/B回収、非ゼロ初期状態、入力再構成、欠損条件・不正時刻・飽和・PD不一致・NaN拒否を検証します。
テストだけはControl System Toolboxを必要とします。
