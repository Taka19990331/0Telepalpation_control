# MC0001_20261105_101724.csv 解析結果

- 解析対象: 終端ゼロを実測できた9掃引
- サンプリング周波数: 2,000 Hz
- 掃引開始: `command_Nm` がゼロから外れる最初のサンプル
- 掃引終了: 非ゼロのチャープ指令後に記録された最初の `chirp_Nm=0` かつ `command_Nm=0` の点
- 周波数応答: 1–100 Hz、対数配置100点。既知の対数チャープ位相に対して4周期Hann窓で正弦・余弦回帰し、位置（rad）/チャープ指令トルク（Nm）を計算

各掃引は終端ゼロ行まで含めて40,001行です。掃引波形の最後の非ゼロサンプルまでの時間は19.9995秒です。10回目は終端ゼロの実測行がないため、解析・同定から除外しています。

元版と同じ閉ループ2次モデル、実測初期状態、試行ごとの角度分散で正規化した等重み誤差で同定した値は **J ≈ 0.0118511 kg·m²、B ≈ 0.0189753 N·m·s/rad** です。正規化角度MSEは約0.007519です。J/Bは入力トルク校正に依存する条件付き等価パラメータです。

解析コードではJ/B・遅延に元版の `qm.fit`・`qm.delay` を、周波数応答に `qm.regression`・`qm.spectra` を使います。ただし元版CSVが持つ基準角メタデータと1秒のphase=2保持データは今回の入力にないため、基準角をPD則から復元し、観測されたphase=1掃引のみで同定しています。この入力範囲の違いは数値比較時に考慮してください。

J/Bを固定して推定した有効無駄時間は、FRF複素応答誤差基準で **Td ≈ 1.487 ms**、時間領域角度誤差基準で **Td ≈ 0.824 ms** です。元版と同じく、FRF基準はゼロ状態の強制応答を遅らせ、時間基準は実測初期状態の自由応答を遅らせずに評価しています。2つの推定値は評価基準が異なるため一致しません。値と探索曲線は `j_b_delay_summary.csv`、`delay_frf_scan.csv`、`delay_time_scan.csv` を参照してください。

元版と同じH1推定ゲインは1 Hzで約0.9545 rad/Nm、100 Hzで約2.050e-4 rad/Nmでした。コヒーレンスは1 Hzで約0.99994、100 Hzで約0.99928です。周波数ごとの値は `frf_ensemble.csv` と `frf_by_trial.csv` を参照してください。
