# 複数試行解析結果

MATLAB R2026a Update 5で実行。全25 CSVのうち13試行を採用しました。
指定の基準2試行は条件一致、追加採用は11試行です。
7件は対象時刻より前かつCSV内メタデータ不足、5件は振幅またはPDゲイン不一致でした。
詳細は `file_selection.csv` と `all_metadata.csv` にあります。

## 同定値と再現性

| 指標 | 結果 |
|---|---:|
| 全13試行の共通J | 0.01168279 kg·m² |
| 全13試行の共通B | 0.02211207 N·m·s/rad |
| 試行別Jの平均 ± 標準偏差 | 0.01168290 ± 0.00003936 kg·m² |
| 試行別Bの平均 ± 標準偏差 | 0.02210971 ± 0.00048876 N·m·s/rad |
| Jの変動係数 | 0.337% |
| Bの変動係数 | 2.211% |
| Coherenceの最小値／中央値 | 0.998917／0.999885 |
| Coherence 0.9未満 | なし（1–100 Hz、100点） |

共通J/Bの内部解は複数初期値からほぼ同一値に収束しました。
Coherenceはチャープ局所回帰の複素係数を試行間で平均した指標です。
通常のWelch法ではありません。高い値は再現性を支持しますが、共通する系統誤差や非線形性を排除しません。

## 実効遅延

- 同じFRF推定器を使った全帯域の複素FRFフィット：**1.46325 ms**
- 30–100 Hzの平均FRF位相傾斜：**1.47699 ms**
- 試行別30–100 Hz位相傾斜：**1.47709 ± 0.00791 ms**、範囲 **1.46156–1.48901 ms**
- 時間領域の角度残差を最小化する遅延：**0.75681 ms**

高周波の約1.45–1.5 msという傾向は再現されました。
30–100 Hzの傾斜回帰はR²=0.9917、位相残差RMSE=0.915°、
遅延なしモデルとのゲイン誤差RMSE=0.181 dBです。
1–10 Hzの傾斜は約0.338 msで、回帰R²は0.214と低くなっています。
したがって、全時間応答の残差が単一の純遅延だけで説明されるわけではありません。
推定基準の違いによる遅延値の差は、そのまま報告しています。

Model Bでは零状態強制応答だけを遅延させ、実測初期状態の自由応答はシフトしていません。
指令・PDの双方が遅れるModel Cは別仮説であり、今回は未実装です。

## 未知試行での比較

取得順の最初の9試行でパラメータを推定し、最新4試行を固定パラメータで予測しました。
検証試行から使った応答情報は初期状態のみです。以下は検証4試行の平均値です。

| 指標 | A：遅延なし | B：FRF推定遅延 | B：時間領域推定遅延 |
|---|---:|---:|---:|
| 角度Fit (%) | 90.991 | 91.010 | 91.031 |
| 角度RMSE (rad) | 0.0362483 | 0.0361741 | 0.0360889 |
| 角速度RMSE (rad/s) | 0.555542 | 0.313150 | 0.420435 |
| FRFゲインRMSE (dB) | 0.20449 | 0.20166 | 0.20300 |
| FRF位相RMSE (deg) | 17.757 | 1.5812 | 8.6264 |

FRF推定遅延は位相誤差を約91%、角速度RMSEを約44%低減しました。
角度Fitの改善は約0.019ポイントと小さく、角度全体の残差は別の誤差要因も含みます。

初期位置とのPearson相関はJ=0.294、B=0.338、30–100 Hz遅延=-0.140でした。
この13試行だけで位置依存性を無視できるとは断定できません。
初期位置は取得順と交絡しているため、これらは記述的な結果です。
