# 複数チャープ解析（MATLAB R2026a、追加Toolbox不要）

`analyze_chirp_multi.m` を開いて実行します。`options.files` が空なら、
指定の基準2件と、それ以降の同条件・健全なCSVをすべて選定します。
ファイル数は固定しません。明示したサブセットでも検査は省略しません。
`captures` にCSVを追加して再実行できます。出力は毎回新しい
`results/yyyyMMdd_HHmmss_SSS` フォルダに作成します。

```matlab
cd('C:\0Telepalpation_control\sys_identification\chirp_analysis_multi')
testResults = runtests('test_qdd_chirp_multi.m');
assertSuccess(testResults)
analyze_chirp_multi
```

`qdd_chirp_multi(struct('makeFigures',false))` で図を省略できます。
単一試行の場合、CoherenceはNaN、未知試行検証は利用不能です。

## 方法

- 全メタデータは `all_metadata.csv`、全件選定表は `file_selection.csv`。
  列名と元キーの対応は `metadata_columns.csv`。不明な追加CONFIGも要確認として除外します。
- CSV内部の重複設定、制御則、実測入力、時刻、終了状態、CAN/フィードバックを検査します。
  記録日時はファイル名由来です。CSVには独立の絶対日時がないため相互検証できません。
- 各試行で `x=q-q0`、PD開始直後の実測角度・速度を初期状態にします。
  初期ゼロトルク平均区間は同定しません。20秒の加振と1秒のPD保持を使います。
- 既存コードを精査してCSVパーサー・制御条件・健全性検査・実測時刻ZOH計算を
  `+qm` に抽出しました。他の処理は複数試行用に分割しました。元フォルダは変更しません。
- J>0、B>=0、B=0の境界解も探索。角度MSEを試行内角度分散で割り、試行間で等重み平均。
  速度は目的関数に入れません。各推定は9初期条件から探索し、収束状況をCSVに保存します。
- 共通100点、4周期窓のHann重み付きチャープ位相回帰。
  係数は cos係数−i sin係数。端点・2周期未満も数値的に計算可能なら残し、診断を保存します。
  複素FRF算術平均とH1を両方出力。Coherenceは独立試行の係数で計算し、Welch法ではありません。
  低Coherenceによる自動除外はありません。
- 遅延は0～5 ms、1.45 msも探索グリッドに含め、局所最小を連続値で精密化します。
  J/B固定で、位相傾斜、全帯域の相対複素FRF誤差、時間角度誤差を比較します。
  位相傾斜は符号付き診断値、モデルBの推定は非負有界です。
- Model Bは**零状態強制応答のみ遅延**させ、初期状態由来の自由応答はPD開始から発展させます。
  分数遅延はZOH区間内の状態遷移を行列指数で評価します。整数サンプル丸めは行いません。
  これは初期履歴不明時の明示的な初期化規約で、実機の測定遅延機構を確定するものではありません。
- 全試行推定は記述的解析。最新ceil(N/4)件を除外してJ/B/Tdを再推定し、
  `training-fixed` の `validation` 行だけを汎化評価とします。初期状態以外は検証応答に合わせません。
  Model C（PDも遅れる別の閉ループモデル）は今回の追加実装に含めていません。

## 出力・解釈

`analysis.mat` に全データ、モデル予測、個別残差、条件、推定・診断を保存。
主要数値はCSV、8種類の図はPNG/FIG、説明は `report.txt` です。
`response_*` は加振・後保持の応答と個別同定の残差を含みます。
全試行の性能差と帯域別誤差、初期位置との相関も保存します。

J/Bは実トルクゲイン未校正の条件付き等価パラメータです。
B=0は摩擦なしの証明ではありません。高Coherenceも線形性の証明にはなりません。
高周波では角度量子化・フィードバック時刻・窓端の影響を確認してください。
初期位置と取得順序は交絡し得るため、相関から位置依存性の原因は断定しません。
合成テストは数値的正しさの検査であり、実機の物理パラメータ可同定性の証明ではありません。
