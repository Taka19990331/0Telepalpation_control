# FR0007 RFOB型摩擦推定

`main.m` をMATLABで実行すると、`results/FR0007` に推定CSV、帯域比較、メタデータ、MATファイル、既定の2図を保存します。既存の `fric_analyze` のコードと結果は変更しません。

## 採用した慣性

- J = 0.0116827933542018 kg·m²、B = 0.0221120689229121 N·m·s/rad（Bは出典情報のみ）
- 出典: `sys_identification/chirp_analysis_multi/results/20261021_164640_755/common_parameters.csv` の `all` 行
- 13試行を選定した複数試行解析。1–9試行を学習、10–13試行を検証に分割し、`all` 値は全データ記述値。Jの試行間CVは report の0.34%。
- 採用モデルは1–100 Hzのチャープを使う角度応答の時間領域フィット（全試行の正規化角度MSE平均）。遅延はJ/Bの固定後に評価されています。
- モデルのJは `kg*m^2`、角度はrad、速度はrad/s。AK80標準MIT出力座標に基づく条件付き等価パラメータで、追加の減速比8換算をしません。
- FR0007メタデータはAK80、CAN2、Motor ID 2、標準MIT設定（`IS_60=0`, `IS_80A=0`）。角度は `position_deg`、速度は `speed_rad_s`、トルクはAK80 MITの内部推定値で、チャープと同じ軸座標です。
- トルクゲインは外部センサで校正されていないため、Jと摩擦トルクの絶対値にはその尺度誤差が残ります。Jが独立に校正された慣性値であることや、摩擦推定値が純粋な軸受摩擦であることは主張しません。

## 方法

フィードバック速度を直接微分しません。CANフィードバック速度と推定トルクは同一スナップショットとして、`feedback_rx_us` に基づく実測Δtで

`u = tau_feedback + J*g*omega`, `y[k] = alpha*u[k] + (1-alpha)*y[k-1]`, `alpha = 1-exp(-g*dt)`, `tau_f_hat = y - J*g*omega`

を計算します。これは一次Qフィルタの厳密ZOH離散化です。初期状態は最初の有効入力に合わせ、トルク段階の切替では状態をリセットしません。2 msを超えるフィードバック間隔では新しい連続区間として初期化します。既定の遮断周波数は5、10、20 Hzです。

対象はPhase 1/3のうち、ファームウェア状態SETTLING/ACQUIRING、`|speed| >= 0.1 rad/s`、ゼロでない指令、ステップ開始から10 ms経過した有効フィードバック行です。OVERSPEED後のCOASTINGやエラー、期限切れ/重複フィードバックを除外します。状態SETTLINGを含め、ブレイクアウェイ後の加速応答を残します。
